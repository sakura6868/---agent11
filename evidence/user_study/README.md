- 223条未关联反馈与基线任务或独立评价来源的关系。
- 授权范围、隐私公开复核与修复后复测记录。

## 补充方式

保留不可覆盖的原始版本，另建更正台账。私有台账建议字段：匿名参与者编号、任务记录编号、运行编号、实际采集时间、应用提交、赛事快照指纹、证据文件及SHA-256、纳入状态、排除原因、复核人和授权范围。

录屏须裁掉账号、联系方式、其他标签与无关桌面内容。经授权的脱敏文件可按需提供给评委；身份映射、同意书和未经公开授权的录像不随源码上传。`private_user_study/` 与 `evidence/user_study/private/` 已加入忽略规则，忽略规则不替代隐私审查。
