# 演示视频交付

本版视频：[演示视频.mp4](../demo/演示视频.mp4)。实际 Chrome 页面录制，约3分40秒，1440×1080、25fps，含中文本地旁白。录制使用隔离 SQLite 与虚构学生画像，关闭外部模型和联网搜索；[本版旁白稿](../docs/DEMO_NARRATION.md)。

演示首页、保存容量画像、新赛道检索、六工具规划、执行清单、零容量停止、明确采用组合、项目看板与时间线、来源提醒及交付边界。页面固定标识“本地隔离演示”。不把模拟变化说成真实官网更新，不宣称线上模型效果或密钥已经撤销。

复录工具：安装 `requirements-dev.txt` 后，Windows 运行 `scripts/build_demo_video.py --prepare` 生成本地中文语音；使用 Playwright CLI 执行 `scripts/record_demo.js` 录屏，再运行 `scripts/build_demo_video.py --recording <实际录屏文件>` 合成。仅处理公开演示内容，脚本不读取云凭据。
