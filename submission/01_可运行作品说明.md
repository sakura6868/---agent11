# 可运行作品说明

目标用户为计算机学院学生，重点服务编程、人工智能、数据分析、网络安全与软件创新方向；通用赛事仍按学生画像与官方资格筛选。

## 作品访问方式

本作品提供可执行源码包与本地部署说明，默认离线可运行，不依赖外部大模型或互联网。启动后访问：

`http://127.0.0.1:8000/`

| 平台 | 启动命令 |
| --- | --- |
| Windows PowerShell | `./start.ps1` |
| macOS / Linux | `chmod +x start.sh && ./start.sh` |
| Docker | `docker compose up --build` |

启动完成后可访问 `GET /health` 检查服务状态，`/docs` 查看接口文档。详细环境、依赖、配置和常见问题见 [../docs/DEPLOYMENT.md](../docs/DEPLOYMENT.md)。

## 评审测试账号

| 项目 | 内容 |
| --- | --- |
| 用户名 | `test` |
| 密码 | `test123` |
| 权限 | 普通学生测试账号，无管理员权限 |
| 初始画像 | 预置测试画像，不对应真实学生身份，具体字段以首次启动后的页面为准 |

该账号在首次启动数据库时幂等创建，初始资料为预置测试画像。登录后可直接查看匹配建议、行动路线、机会提醒和智能顾问；右上角可切换内置测试画像，展示不同条件下的推荐差异。请勿在公开部署中将测试账号用于真实个人信息或真实项目数据。测试账号不计入用户试用样本；队友候选也不是实际学生联系人。具体来源和用途见 [数据来源与证据边界](../docs/DATA_PROVENANCE.md)。

## 最短验收路径

1. 使用测试账号登录，进入首页查看“今日聚焦”。
2. 在“赛事大厅”按正式名称检索并打开赛事详情。
3. 进入“匹配建议”查看资格、时间和能力缺口解释。
4. 将赛事加入“我的项目”，切换列表、看板、日历与时间线。
5. 打开“智能顾问”，输入“推荐三场值得投入的比赛”。

若未配置外网、LLM 或 Chroma，系统仍使用本地可信赛事库返回核心推荐与规则问答。
