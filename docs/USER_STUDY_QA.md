## 复核方式

采集者可用私有源表按以下步骤复核，无需公开个人数据：

1. 对源文件计算SHA-256，与报告指纹比较。
2. 各表只计首列ID非空行，按任务ID及“结果”计数；失败、超时不删。
3. T04总完成率=(18+4)/24；T05总完成率=(16+5)/24。独立率分别18/24、16/24。
4. 评分使用数值列算术平均，即时与后续分别统计。
5. 计时由结束−开始得到秒数，按照报告第6节筛选主对照，逐对算节省比例后平均。
6. 将证据编号对应已有文件、日期、版本及授权，由独立人员核验后另记状态，不倒填为本轮已通过。
