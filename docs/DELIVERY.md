# 纯净参赛版交付

源码目录仅保留运行代码、官方事实与证据、当前评测、技术说明和一段正式演示视频。当前版来自功能验收后的源码快照，使用全新Git初始化，不继承旧仓库历史；没有自动云部署配置、旧提交ZIP、私人环境、运行数据库或历史试用报告。

本次从独立目录重新执行正式与完整回归、模板评测及实际浏览器检查；Python沿用已安装依赖的环境，数据库独立，不宣称重新安装了全部依赖或通过线上验收。当前代码与数据指纹同JSON评测报告对应。

ZIP由 `scripts/create_release_bundle.py` 生成。SHA256文件和解压运行检查作为ZIP旁的校验附件提供；含ZIP本身指纹的验收报告不嵌入该ZIP，以避免自引用。上传新仓库请使用本目录或ZIP内容，不复制原仓库的 `.git`、`.env` 或运行数据库。

公开Git仓库的历史与云平台凭据有效性相互独立；提交者应在平台管理其凭据。此交付不携带任何旧值或新值。
