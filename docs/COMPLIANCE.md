# 数据、隐私与合规说明

赛事资料来自公开官方网页、PDF与Word通知；保存来源链接、获取日期、检查日期、字段原文定位及文档SHA256。有官网链接不等于关键规则已核实，未知值保留未知，候选不会被正式评分或加入项目。

目录统计以 [提交快照](SUBMISSION_STATUS.md) 为准。检索按赛事、年份和版本隔离，联网搜索仅作参考，官方变化经人工审核后才更新事实。参赛资格最终以官网最新通知和学校要求为准。

演示使用虚构学生画像。应用仅收集用户主动填写的学历、专业、技能、经历、团队人数与每周时间，不要求身份证号、详细住址或私密成绩。用户可删除画像及关联项目，公共资料和其他用户数据不受影响。

用户会话及资源所有权校验保护个人数据，管理写入使用独立令牌。规划模型只看到脱敏目标与公开聚合观察；规划不会自动写画像、创建项目或报名。第三方模型与联网服务默认关闭，启用时由部署者确认其条款与隐私规则。

此交付没有私人 `.env`、真实密钥、运行数据库或旧Git历史。模式扫描属于有限检查，不是完整安全审计；线上凭据管理及生产验收由部署者另行完成。
