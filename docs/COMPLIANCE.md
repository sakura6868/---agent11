# 数据、隐私与合规说明

赛事资料来自公开官方网页、PDF与Word通知；保存来源链接、获取日期、检查日期、字段原文定位及文档SHA256。有官网链接不等于关键规则已核实，未知值保留未知，候选不会被正式评分或加入项目。

目录统计以 [提交快照](SUBMISSION_STATUS.md) 为准。检索按赛事、年份和版本隔离，联网搜索仅作参考，官方变化经人工审核后才更新事实。参赛资格最终以官网最新通知和学校要求为准。

应用支持用户自行填写和保存学历、专业、技能、经历、团队人数与每周时间，不要求身份证号、详细住址或私密成绩。为便于功能体验，另提供预置测试账号与测试画像；它们不对应真实学生身份，也不作为学生试用样本。用户可删除自己的画像及关联项目，公共资料和其他用户数据不受影响。

用户会话及资源所有权校验保护个人数据，管理写入使用独立令牌。规划模型只看到脱敏目标与公开聚合观察；规划不会自动写画像、创建项目或报名。第三方模型与联网服务默认关闭，启用时由部署者确认其条款与隐私规则。

此交付没有私人 `.env`、真实密钥、运行数据库或旧Git历史。模式扫描属于有限检查，不是完整安全审计；线上凭据管理及生产验收由部署者另行完成。

## 用户试用材料的独立公开范围

当前[试用报告](USER_STUDY.md)按《数据3.xlsx》逐行字段复算，只公开聚合结果、方法和源指纹。提供者说明为实测记录，但独立操作凭证、身份、版本绑定与授权尚待核验。预置测试账号与试用记录分开，不导入逐人明细或将测试账号计入参与者。

官方赛事资料、用户记录、测试画像和工程夹具的来源及允许用途见 [数据来源与证据边界](DATA_PROVENANCE.md)。队友候选当前仅来自预置测试画像；雷达演练使用人工编写的通知内容。这两类内容不能当作真实队友招募或实际官网更新的证据。

此次仓库补充仅保存聚合人数、任务结果、量表均值、反馈类别、计时统计、方法和文件指纹；不复制源工作簿、参与者身份映射、联系方式、私人账户、逐人画像、个人原话或原始同意书。当前源工作簿已被只读分析，仍由采集者私有保管，不上传。旧JSON及其复算脚本保留历史范围，不能作为当前批次统计或新版材料核验入口。

当前工作簿没有知情同意、录屏或匿名引用许可字段，不能沿用旧模板的授权状态；本次未独立核验授权凭证。发布前由采集者确认统计公开范围、截图脱敏、原话许可、保存期限、访问人和撤回渠道，并在私有台账记录。未经确认不得公开录屏、原话和个人明细；旧JSON的 `privacy_release_review_completed=false` 属于历史状态，本轮同样未完成独立授权核验，不宣称全部研究合规审查已经完成。
